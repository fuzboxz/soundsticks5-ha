# 0.9.1 — First Strike

First public release of SoundSticks 5 for Home Assistant.

## In this release

- Local Bluetooth BLE control of volume, lighting on/off, six lighting themes, brightness, color, speed, seven-band EQ, and device settings.
- The Lovelace card ships and updates with the integration; it registers automatically in UI-managed resources mode and can be added straight to a dashboard.
- Playback control supports three modes: auto, specific media entity, and BLE-only; title and artist are read from the selected media entity.
- Scene presets support save, apply, and delete, and can be driven from HA actions for automations.
- Bundled "The Sound Chamber of 5" integration icon with light and dark variants.
- When the BLE connection fails, troubleshooting hints cover app contention, range, and proxy state, and clearly distinguish Bluetooth BLE control from Bluetooth audio playback.

## Installation

The recommended install is via HACS custom repository `neqq3/soundsticks5-ha`, category **Integration**. After installing, restart HA, add the integration, then refresh your browser and add the SoundSticks 5 card.

For manual installation, download the `soundsticks5-0.9.1.zip` attachment and copy its `custom_components/soundsticks5` into HA's `/config/custom_components/soundsticks5`.

- [First use: integration and Lovelace card](https://github.com/neqq3/soundsticks5-ha/blob/v0.9.1/docs/getting-started.md)
- [Playback source configuration](https://github.com/neqq3/soundsticks5-ha/blob/v0.9.1/soundsticks5-card/PLAYBACK.md)

## Requirements and boundaries

- Minimum HA version is **2025.12.2**; the bundled integration icon requires **2026.3+**.
- A connectable Bluetooth BLE adapter or proxy is required; advertisement-only proxies are not enough.
- This integration provides Bluetooth BLE control only — it does not transport audio and does not promise to wake a deeply sleeping speaker over BLE.
- Title and artist depend on the actual playback source or on what the speaker reports; music playing over Bluetooth audio does not guarantee track info arrives over BLE.
- Validation is based on one standard SoundSticks 5; more firmware, regional, and proxy combinations still need testing.
- When card resources are managed via YAML, the resource URL must be added manually — see the getting-started guide.

Earlier `1.x` numbers were internal development versions; `0.9.1` is the starting point of the first public release. Testers on a dev build who don't see an update prompt can re-download in HACS and select `v0.9.1`. There is no need to delete the integration or existing presets.
